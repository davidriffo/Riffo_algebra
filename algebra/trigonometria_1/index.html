    Cálculo y Simplificación de Expresiones Trigonométricas

    Problema 1: Haciendo uso de propiedades de las funciones trigonométricas, calcule el valor de:

    \[\cos \left( \frac{7\pi}{6} \right)\]
    Ver Desarrollo Para reducir al primer cuadrante, identificamos en qué cuadrante se encuentra el ángulo. Sabemos que \(\frac{7\pi}{6} = \pi + \frac{\pi}{6}\), lo cual ubica al ángulo en el tercer cuadrante. En el tercer cuadrante, la función coseno es negativa. Aplicando la propiedad de reducción: $$\cos\left(\pi + \frac{\pi}{6}\right) = -\cos\left(\frac{\pi}{6}\right)$$ Evaluando el ángulo conocido del primer cuadrante: $$-\cos\left(\frac{\pi}{6}\right) = -\frac{\sqrt{3}}{2}$$

    Problema 2: Haciendo uso de propiedades de las funciones trigonométricas, calcule el valor de:

    \[\tan \left( \frac{5\pi}{3} \right)\]
    Ver Desarrollo Expresamos el ángulo en relación con el eje X. Notamos que \(\frac{5\pi}{3} = 2\pi - \frac{\pi}{3}\), lo que lo sitúa en el cuarto cuadrante. En el cuarto cuadrante, la función tangente es negativa. Aplicando la propiedad correspondiente: $$\tan\left(2\pi - \frac{\pi}{3}\right) = -\tan\left(\frac{\pi}{3}\right)$$ Calculando el valor exacto: $$-\tan\left(\frac{\pi}{3}\right) = -\sqrt{3}$$

    Problema 3: Haciendo uso de propiedades de las funciones trigonométricas, calcule el valor de:

    \[\cot \left( \frac{13\pi}{4} \right)\]
    Ver Desarrollo El ángulo \(\frac{13\pi}{4}\) es mayor a un giro completo (\(2\pi\)). Primero eliminamos los giros enteros: $$\frac{13\pi}{4} = \frac{8\pi}{4} + \frac{5\pi}{4} = 2\pi + \frac{5\pi}{4}$$ El ángulo coterminal es \(\frac{5\pi}{4}\). Ahora lo ubicamos respecto al eje X: \(\frac{5\pi}{4} = \pi + \frac{\pi}{4}\) (tercer cuadrante). En el tercer cuadrante, la cotangente es positiva: $$\cot\left(\pi + \frac{\pi}{4}\right) = \cot\left(\frac{\pi}{4}\right) = 1$$

    Problema 4: Haciendo uso de propiedades de las funciones trigonométricas, calcule el valor de:

    \[\csc \left( \frac{17\pi}{6} \right)\]
    Ver Desarrollo Primero buscamos el ángulo coterminal en la primera vuelta, restando múltiplos de \(2\pi\): $$\frac{17\pi}{6} = \frac{12\pi}{6} + \frac{5\pi}{6} = 2\pi + \frac{5\pi}{6}$$ Trabajamos con \(\frac{5\pi}{6}\), el cual está en el segundo cuadrante, ya que \(\frac{5\pi}{6} = \pi - \frac{\pi}{6}\). En el segundo cuadrante, la función cosecante es positiva (igual que el seno): $$\csc\left(\pi - \frac{\pi}{6}\right) = \csc\left(\frac{\pi}{6}\right) = 2$$

    Problema 5: Haciendo uso de propiedades de las funciones trigonométricas, calcule el valor de:

    \[\operatorname{sen} \left( -\frac{4\pi}{3} \right)\]
    Ver Desarrollo Primero utilizamos la propiedad de paridad. La función seno es impar, por lo tanto: $$\operatorname{sen}\left(-\frac{4\pi}{3}\right) = -\operatorname{sen}\left(\frac{4\pi}{3}\right)$$ Ubicamos el ángulo \(\frac{4\pi}{3}\) en el tercer cuadrante (\(\pi + \frac{\pi}{3}\)). En este cuadrante, el seno es negativo: $$-\operatorname{sen}\left(\pi + \frac{\pi}{3}\right) = -\left(-\operatorname{sen}\left(\frac{\pi}{3}\right)\right) = \operatorname{sen}\left(\frac{\pi}{3}\right)$$ Evaluando: $$\operatorname{sen}\left(\frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}$$

    Problema 6: Haciendo uso de propiedades de las funciones trigonométricas, calcule el valor de:

    \[\sec \left( -\frac{7\pi}{4} \right)\]
    Ver Desarrollo Aplicamos paridad. La función secante (al igual que el coseno) es par, por lo tanto absorbe el signo negativo: $$\sec\left(-\frac{7\pi}{4}\right) = \sec\left(\frac{7\pi}{4}\right)$$ El ángulo \(\frac{7\pi}{4}\) se encuentra en el cuarto cuadrante y se puede escribir como \(2\pi - \frac{\pi}{4}\). La secante es positiva en este cuadrante: $$\sec\left(2\pi - \frac{\pi}{4}\right) = \sec\left(\frac{\pi}{4}\right) = \sqrt{2}$$

    Problema 7: Haciendo uso de propiedades de las funciones trigonométricas, calcule el valor de:

    \[\cos \left( \frac{31\pi}{3} \right)\]
    Ver Desarrollo Dividimos para encontrar la cantidad de giros completos: $$\frac{31\pi}{3} = 10\pi + \frac{\pi}{3}$$ Dado que \(10\pi\) representa 5 giros completos, el ángulo coterminal es directamente \(\frac{\pi}{3}\), el cual ya está en el primer cuadrante. $$\cos\left(10\pi + \frac{\pi}{3}\right) = \cos\left(\frac{\pi}{3}\right) = \frac{1}{2}$$

    Problema 8: Haciendo uso de propiedades de las funciones trigonométricas, calcule el valor de:

    \[\tan \left( \frac{25\pi}{6} \right)\]
    Ver Desarrollo Encontramos el ángulo coterminal restando múltiplos pares de \(\pi\): $$\frac{25\pi}{6} = \frac{24\pi}{6} + \frac{\pi}{6} = 4\pi + \frac{\pi}{6}$$ Como \(4\pi\) son dos vueltas completas, nos quedamos con \(\frac{\pi}{6}\). $$\tan\left(4\pi + \frac{\pi}{6}\right) = \tan\left(\frac{\pi}{6}\right) = \frac{\sqrt{3}}{3}$$

    Problema 9: Haciendo uso de propiedades de las funciones trigonométricas, calcule el valor de:

    \[\operatorname{sen} \left( -\frac{11\pi}{4} \right)\]
    Ver Desarrollo Por paridad (el seno es impar), extraemos el signo negativo: $$-\operatorname{sen}\left(\frac{11\pi}{4}\right)$$ Reducimos el ángulo restando una vuelta (\(2\pi = \frac{8\pi}{4}\)): $$\frac{11\pi}{4} = 2\pi + \frac{3\pi}{4}$$ El ángulo es coterminal con \(\frac{3\pi}{4}\) (segundo cuadrante). En el segundo cuadrante, el seno es positivo: $$-\operatorname{sen}\left(2\pi + \frac{3\pi}{4}\right) = -\operatorname{sen}\left(\frac{3\pi}{4}\right)$$ Reducimos al primer cuadrante \(\frac{3\pi}{4} = \pi - \frac{\pi}{4}\): $$-\operatorname{sen}\left(\pi - \frac{\pi}{4}\right) = -\operatorname{sen}\left(\frac{\pi}{4}\right) = -\frac{\sqrt{2}}{2}$$

    Problema 10: Haciendo uso de propiedades de las funciones trigonométricas, calcule el valor de:

    \[\csc \left( \frac{53\pi}{6} \right)\]
    Ver Desarrollo Extraemos los giros completos buscando el múltiplo par de \(\pi\) más cercano a \(\frac{53}{6}\). Sabemos que \(6 \times 8 = 48\), por lo que separamos el ángulo así: $$\frac{53\pi}{6} = \frac{48\pi}{6} + \frac{5\pi}{6} = 8\pi + \frac{5\pi}{6}$$ Dado que \(8\pi\) corresponde a 4 giros completos, el ángulo coterminal es \(\frac{5\pi}{6}\). Este ángulo se ubica en el segundo cuadrante y se puede escribir como \(\pi - \frac{\pi}{6}\). La cosecante en el segundo cuadrante es positiva: $$\csc\left(8\pi + \frac{5\pi}{6}\right) = \csc\left(\frac{5\pi}{6}\right) = \csc\left(\pi - \frac{\pi}{6}\right)$$ Reduciendo al primer cuadrante y evaluando: $$\csc\left(\frac{\pi}{6}\right) = 2$$
